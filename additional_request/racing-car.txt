# Самодостаточное уточнение request_suspension.yaml по математике эталона.
# Сохранён формат: имя запроса -> одно текстовое описание для генерации модели.
Эталонный запрос: |
  ## Назначение и границы модели

  Построй автономную математическую модель вертикальной динамики подвески
  Макферсона с шиной, прогрессивной пружиной и двутрубным амортизатором.
  Ниже полностью заданы необходимые уравнения и численные соглашения.
  Используй именно эти зависимости, включая принятую балансировку начальных
  сил; дополнительные физические состояния и альтернативные законы не вводи.
  Реализация должна работать без импорта модулей проекта; для вычислений
  достаточно Python и NumPy. Matplotlib допустим для визуализации.

  Модель имеет две динамические степени свободы. Состояние строго упорядочено:
    y = [z_s, v_s, z_u, v_u].
  z_s и z_u — вертикальные отклонения подрессоренной массы и центра колеса
  от принятого исходного состояния на ровной дороге; положительное направление
  вверх. v_s = dz_s/dt, v_u = dz_u/dt. Все единицы — СИ, углы — радианы.
  Геометрические координаты точек ниже относятся к исходной конфигурации;
  их Z-компоненты не являются значениями динамических координат z_s и z_u.

  Входы: пространственный профиль h(x) и постоянная продольная скорость V.
  Продольная координата x = V*t. Значение по умолчанию V = 2.5 м/с.
  Основные выходы: z_s, v_s, z_u, v_u во все моменты заданной сетки времени.
  Стабилизатор, рулевое управление, вращение колеса вокруг его оси, гистерезис
  амортизатора, упругость звеньев и дополнительные инерции не учитываются.
  Кинематика рассчитывается алгебраически, а не как дополнительные ОДУ.

  ## Параметры масс и геометрии

  m_s = 365 кг; m_u = 45 кг; g = 9.81 м/с^2.
  Система геометрических координат: X вперёд, Y влево, Z вверх.
  Координаты и направления:
    A  = [-0.08382, 0.54102, 0.46863] — верхняя опора стойки, м;
    B0 = [0.02794, 0.66294, -0.10414] — исходная нижняя шаровая опора, м;
    P1 = [0.27051, 0.34544, -0.05969] — первый внутренний шарнир рычага, м;
    P2 = [-0.04318, 0.37338, -0.12573] — второй внутренний шарнир рычага, м;
    D0 = [-0.00508, 0.61976, -0.00127] — нижнее крепление амортизатора, м;
    W0 = [0.0, 0.750062, 0.0] — центр колеса в исходной конфигурации, м;
    e_w = [0.0, 1.0, 0.0] — исходное направление оси колеса влево.

  ## Замкнутая кинематическая модель

  Нижний рычаг абсолютно жёсткий и вращается вокруг оси P1-P2. Расстояния
  от шаровой опоры B до P1 и P2 сохраняются. Верхняя опора A неподвижна
  в системе кузова. Положение D и W задаётся жёсткими смещениями от B
  в локальном базисе стойки. Дополнительный поворот вокруг оси стойки
  исключается правилом минимального пространственного вращения ниже.

  Определим unit(a) = a/||a||; dot — скалярное, cross — векторное произведение.
  Построение окружности движения B:
    e12 = unit(P2 - P1);
    d = ||P2 - P1||;
    l1 = ||B0 - P1||; l2 = ||B0 - P2||;
    a = (l1^2 - l2^2 + d^2)/(2*d);
    C = P1 + a*e12;
    r = sqrt(max(l1^2 - a^2, 0));
    n1 = unit(B0 - C); n2 = cross(e12, n1);
    B(phi) = C + r*(n1*cos(phi) + n2*sin(phi)).
  Здесь phi = 0 соответствует B0.

  Исходный ортонормированный базис:
    s0 = unit(A - B0);
    q0 = unit(e_w - dot(e_w, s0)*s0);
    t0 = cross(s0, q0);
    R0 = матрица со столбцами [q0, t0, s0];
    rho_D = transpose(R0)*(D0 - B0);
    rho_W = transpose(R0)*(W0 - B0).

  Для каждого phi вычислить s = unit(A - B(phi)). Матрица U — минимальное
  вращение, переводящее s0 в s. Для v = cross(s0, s), c = dot(s0, s):
    U = I + [v]_x + [v]_x*[v]_x/(1 + c),
  где [v]_x*a = cross(v, a). При c > 1 - 1e-12 использовать U = I.
  При c < -1 + 1e-12 выбрать helper = [1,0,0], если abs(s0[0]) < 0.9,
  иначе helper = [0,1,0]; n = unit(cross(s0, helper)); U = I + 2*[n]_x^2.
  Далее:
    R(phi) = U*R0;
    D(phi) = B(phi) + R(phi)*rho_D;
    W(phi) = B(phi) + R(phi)*rho_W;
    L0 = ||D0 - A||;
    L(phi) = ||D(phi) - A||;
    q(phi) = W(phi)[Z] - W0[Z];
    c_s(phi) = c_d(phi) = L0 - L(phi).
  c_s — дополнительное сжатие пружины, c_d — ход амортизатора, сжатие плюс.
  Пружина и амортизатор имеют одинаковые зависимости хода от q.

  Предварительно построить таблицу на 1001 равномерно расположенной точке
  phi от -0.35 до +0.35 включительно. Отсортировать строки по q.
  В узлах таблицы найти J_s = d(c_s)/dq и J_d = d(c_d)/dq с помощью
  numpy.gradient(c_s, q) и numpy.gradient(c_d, q), с edge_order=1.
  При вычислении динамики использовать q = z_u - z_s и q_dot = v_u - v_s.
  Значения c_s(q), c_d(q), J_s(q), J_d(q) интерполировать независимо
  линейно, как numpy.interp. Вне диапазона таблицы возвращать ближайшее
  граничное значение каждой величины; линейную экстраполяцию не выполнять.
  Это численное соглашение эталона, а не модель физических ограничителей хода.
  Скорость сжатия амортизатора w = J_d(q)*q_dot.
  Нельзя заменять кинематическую таблицу проекцией наклона стойки или
  вычислять её аргумент по абсолютной координате z_u.

  ## Пружина

  Параметры: k = 35000 Н/м; k_ex = 60 Н; beta = 30 1/м;
  F_pre = 7600 Н; exp_arg_max = 8.
  Осевая сила положительна в направлении поддержки подрессоренной массы:
    F_s(c_s) = F_pre + k*c_s + k_ex*(exp(min(beta*c_s, 8)) - 1).
  Ограничивается только верхнее значение аргумента экспоненты.
  Дополнительный порог включения прогрессии отсутствует. На растяжении
  используется та же формула; отсечение силы пружины нулём не вводится.
  Преднатяг не пересчитывается из m_s*g.

  ## Двутрубный амортизатор: параметры

  A_p = 1.5e-3 м^2 — площадь поршня;
  A_r = 6.0e-4 м^2 — площадь штока;
  A_a = A_p - A_r = 9.0e-4 м^2 — кольцевая площадь;
  F_c = 40 Н; c_f = 200 Н*с/м;
  w_eps = 0.01 м/с — масштаб сглаживания сухого трения;
  F_gas = 299.22 Н — постоянный газовый подпор;
  eta_oil = 1; eta_gas = 1 — множители гидравлики и газового подпора.
  Эквивалентный расчёт F_gas = (600000 - 101300)*A_r.
  Давление газа и температура не являются динамическими состояниями.

  rho = 850 кг/м^3; C_d = 0.7;
  A_leak_p = 2.2e-6 м^2; A_leak_b = 2.4e-6 м^2;
  A_port = 50.0e-6 м^2 для обоих клапанов.
  Для квадратичных коэффициентов использовать точную формулу:
    b2(A) = rho/(2*(C_d*A)^2).
  Приоритет имеют вычисленные коэффициенты, а не округлённые значения
  из исходного описания: это обеспечивает совпадение с эталоном.

  Поршневой клапан:
    leak_b1 = 5.0e8 Па*с/м^3;
    leak_b2 = b2(A_leak_p), приблизительно 1.792039129701467e14 Па*с^2/м^6;
    port_b1 = 0; port_b2 = b2(A_port);
    p0 = 5.0e5 Па; K = 6.4e15 Па^2*с/м^3.
  Донный клапан:
    leak_b1 = 5.0e8 Па*с/м^3;
    leak_b2 = b2(A_leak_b), приблизительно 1.505810657596372e14 Па*с^2/м^6;
    port_b1 = 0; port_b2 = b2(A_port);
    p0 = 4.0e5 Па; K = 5.0e15 Па^2*с/м^3.
  Для обоих port_b2 приблизительно 3.469387755102042e11 Па*с^2/м^6.

  ## Гидравлическая схема и закон силы амортизатора

  Для каждого клапана утечка и открывающаяся ветвь соединены параллельно.
  Основной канал port соединён последовательно с этим параллельным узлом.
  Для расхода по модулю Q >= 0 найти давление p >= 0 из уравнения:
    Q_leak(p) + Q_open(p) = Q;
    Q_leak(p) = (-leak_b1 + sqrt(leak_b1^2 + 4*leak_b2*p))/(2*leak_b2);
    Q_open(p) = 0, если p < p0;
    Q_open(p) = (p - p0)*p/K, если p >= p0.
  При p <= 0 расход утечки равен нулю. Для общего случая leak_b2 <= 0
  использовать Q_leak = p/leak_b1 при leak_b1 > 0, иначе ноль.
  Полный положительный перепад:
    D(Q) = p + port_b1*Q + port_b2*Q^2.
  При Q = 0 принять p = 0 и D = 0.
  Для Q > 0 решить уравнение бисекцией: начальный интервал [0, 1e5] Па,
  удваивать верхнюю границу до неотрицательной невязки, не более 200 раз;
  затем выполнить 60 делений интервала пополам и вернуть его середину.
  Невязка равна Q_leak(p) + Q_open(p) - Q.

  w обозначает осевую скорость сжатия амортизатора, сжатие положительно.
  Сила гидравлики на сжатии определяется только донным клапаном:
    если w > 0: Q = A_r*w; F_hyd = +A_r*D_base(Q).
  На отбое используется только поршневой клапан:
    если w < 0: Q = A_a*(-w); F_hyd = -A_a*D_piston(Q).
  При w = 0: F_hyd = 0.
  Таким образом, характеристика сжатия и отбоя несимметрична.
  Одновременное суммирование сил двух клапанов для обоих направлений
  или сложение перепадов утечки и открывающейся ветви недопустимо.

  Трение и полная осевая сила:
    F_fric(w) = F_c*tanh(w/w_eps) + c_f*w;
    F_d(w) = eta_oil*F_hyd(w) + F_fric(w) + eta_gas*F_gas.
  F_d положительна в направлении поддержки подрессоренной массы.
  При w = 0 сила равна газовому подпору, а не нулю.

  ## Перенос осевых сил в вертикальное направление

  Использовать передаточные отношения из кинематической таблицы:
    S_s(q) = J_s(q)*F_s(c_s(q));
    S_d(q, q_dot) = J_d(q)*F_d(J_d(q)*q_dot);
    S(q, q_dot) = S_s(q) + S_d(q, q_dot).
  S — полная вертикальная сила подвески на подрессоренную массу вверх.
  На неподрессоренную массу действует противоположная сила.
  Дополнительные косинусы углов поверх J_s и J_d не вводить.

  ## Огибающая дорожного профиля

  R_t = 0.31785 м — радиус шины.
  Для произвольного h(x) определить эффективную высоту опоры:
    H(x) = max_i [h(x + xi_i) + sqrt(max(R_t^2 - xi_i^2, 0)) - R_t],
  где xi_i — 161 равномерная точка от -R_t до +R_t включительно.
  Это алгебраическое вычисление по всему окну, включая участок впереди
  колеса; история ранее пройденных точек не используется.
  H — приращение эффективной высоты дороги, а не высота центра колеса.
  На ровной дороге h = 0 обязательно H = 0.

  Вертикальная скорость эффективной опоры:
    H_dot(x) = V*(H(x + dx) - H(x - dx))/(2*dx), dx = 0.001 м.
  В каждом вызове правой части вычислять H и H_dot в x = V*t, в том числе
  на промежуточных стадиях интегратора. Специальное сглаживание ступеньки
  и обнаружение событий при её прохождении не требуются.

  ## Шина и принятая балансировка исходного состояния

  k_t = 180000 Н/м; c_t = 1500 Н*с/м.
  Сначала при нулевом относительном ходе и нулевой скорости определить:
    S0 = S(0, 0);
    T0 = S0 + m_u*g;
    delta0 = T0/k_t.
  Далее:
    delta = delta0 + H(V*t) - z_u;
    delta_dot = H_dot(V*t) - v_u;
    T_raw = k_t*delta + c_t*delta_dot;
    T = max(T_raw, 0).
  T — полная сила шины вверх на неподрессоренную массу.
  Радиус R_t повторно в delta не добавлять.
  Для соответствия эталону используется именно отсечение полной силы:
  отдельное принудительное T = 0 при delta <= 0 не вводить, если T_raw > 0.
  Это упрощённый закон односторонней силы, а не событийная модель контакта.

  Исходное состояние балансируется постоянными опорными силами S0 и T0.
  Это соглашение для воспроизведения эталона, а не результат решения
  полной статической задачи автомобиля под действием собственного веса.
  В частности, равенство S0 = m_s*g не навязывается. При этих параметрах
  оно не выполняется. Не следует автоматически исправлять преднатяг,
  искать другое положение статического равновесия или заменять S0 на m_s*g:
  такие изменения зададут другую модель.

  ## Уравнения движения

  Пусть q = z_u - z_s; q_dot = v_u - v_s.
  Силы относительно принятого исходного состояния:
    dS = S(q, q_dot) - S0;
    dT = T - T0.
  Правая часть ОДУ:
    dz_s/dt = v_s;
    dv_s/dt = dS/m_s;
    dz_u/dt = v_u;
    dv_u/dt = (dT - dS)/m_u.
  Отдельные слагаемые -m_s*g и -m_u*g в эти уравнения не добавлять:
  принятая балансировка уже учтена. g используется при определении T0.
  Начальное состояние по умолчанию y(0) = [0, 0, 0, 0].


  По умолчанию дорога — прямоугольная площадка:
    h(x) = 0.04 м при 1.0 <= x <= 3.0 м, иначе 0.
  Дополнительный сценарий — ступенька:
    h(x) = 0.04 м при x >= 1.0 м, иначе 0.

  ## Диагностика и контроль соответствия

  Вернуть массивы t, x = V*t, z_s, v_s, z_u, v_u; дополнительно H, H_dot,
  q, delta, c_s, c_d и вертикальные силы относительно исходного состояния:
    spring_vertical_force = S_s(q) - S_s(0);
    damper_vertical_force = S_d(q, q_dot) - S_d(0, 0);
    suspension_vertical_force = S(q, q_dot) - S0;
    tire_vertical_force = T - T0.
  Различать полную силу T >= 0 и её приращение T - T0: последнее может
  быть отрицательным. Диагностику вычислять на сохранённых состояниях,
  а не брать из последней промежуточной стадии RK4.
  Визуализация допустима, но не меняет физические уравнения.

  Контрольные значения для указанных параметров, с допустимым отклонением
  1e-6 по абсолютной величине для приведённых чисел:
    c_s(0) = c_d(0) = 0;
    J_s(0) = J_d(0) приблизительно 0.9770245641261587;
    S0 приблизительно 7717.731977436635 Н;
    T0 приблизительно 8159.181977436635 Н;
    delta0 приблизительно 0.04532878876353686 м;
    F_d(+0.1 м/с) приблизительно 639.0429644185829 Н;
    F_d(-0.1 м/с) приблизительно -426.4161634097681 Н;
    F_d(0) = 299.22 Н.
  На плоской дороге h(x) = 0 при y = [0,0,0,0] правая часть должна
  быть нулевой с точностью округления и состояние должно сохраняться.
  Прибавление одной константы к z_s и z_u не должно менять кинематику
  подвески, поскольку она зависит от q; сила шины при этом может измениться.
  Для всей модели не требуется совпадение структуры классов или имён
  функций с какой-либо внешней реализацией: важны уравнения, параметры,
  численные соглашения и результаты контрольных расчётов выше.
