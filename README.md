## Где версии системы

В ветках проекта есть папка system. В ней есть две версии. Первая версия создана для моделирования двухзвенного маятника. Вторая модель была создана для моделирования подвески гоночного автомобиля.

## Как запускать
### Первая система
Нужно вызвать файл main.py и указать yml файл с описаниями объектов. Yml файл должен содержать описание запроса и название запроса, пример можно найти в ветке первой системы.
`python main.py request.yaml`

### Вторая система
Вторую мультиагентную систему можно аналогично запустить
`python main.py request/requst_suspension.yaml`

Если не требуется отчёт о проделанной работе, то можно отключить работу последнего агента 
`python main.py request/requst_suspension.yaml --skip-insight`

Можно еще указать папку для сохранения всех артефактов работы системы. По умолчанию это папка results
`python main.py request_suspension.yaml --skip-insight --output-dir results`

Артефакты которые можно получить после запуска:
specification.json — параметры, единицы и допущения;
physical_subsystems.md — физические подсистемы и обмен величинами;
subsystems.py — функции подсистем;
model.py — самостоятельная запускаемая модель;
simulation_report.md — объяснение модели, если последний агент включён;
прежние <имя запроса>.py, <имя запроса>.md и trace.json.

#### Launcher
Суть лаунчера в том, что после генерации модели можно сразу же провалидировать её. Берётся траектория z_u и сравнивается
с помощью расстояния L2. При расстоянии L2 < 1 можно считать, что модель адекватная. Ошибка *абсолютная*
`python launcher.py --prompt-file suspension_request.txt`
