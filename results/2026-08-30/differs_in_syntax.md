Уравнения движения получены через граф Лагранжа для двойного маятника с двумя точечными массами на массless звеньях: dθ1/dt = ω1, dθ2/dt = ω2, а ускорения θ1̈ и θ2̈ задаются из линейной системы, полученной из двух уравнений движения, с Δ = θ1 − θ2 и матрицей M = [ [ (m1+m2) l1, m2 l2 cosΔ ], [ m2 l1 cosΔ, m2 l2 ] ]; правой частью b = [ b1, b2 ]^T, где b1 = − m2 l2 ω2² sinΔ − (m1+m2) g sinθ1, b2 = m2 l1 ω1² sinΔ − m2 g sinθ2. В результате выводим траектории θ1(t), θ2(t), ω1(t), ω2(t); при необходимости можно дополнительно вывести Cartesian-координаты грузов: x1 = l1 sinθ1, y1 = l1 cosθ1; x2 = x1 + l2 sinθ2, y2 = y1 + l2 cosθ2. Принятые значения параметров (l1, l2, m1, m2, g, начальные θ и ω) являются задаными пользователем или выводимыми по умолчанию; ускорения на t=0 не задаются напрямую, а вычисляются из уравнений движения и в начальный момент обычно не равны нулю, что согласуется с данными условиями «начальные скорости равны нулю».

### ai

Ниже представлен небольшой отчёт об описанной симуляции двойного маятника (абсолютно жёсткие невесомые звенья, точечные массы на концах), оформленный для студентов. Он охватывает цель, физику, структуру кода и практические моменты анализа.

1) Цель моделирования (Simulation Goal)
- Что моделируется: динамика двойного маятника с двумя массами m1 и m2 на концах двух последовательных жёстких ненагруженных звеньев длиной l1 и l2 в поле гравитации g.
- Идея: описать темпоральное эволюционирование угловых координат θ1(t) и θ2(t) и их производных (ω1 = dθ1/dt, ω2 = dθ2/dt) под воздействием гравитации и взаимного влияния звеньев.
- Начальные условия: θ1(0) = 10°, θ2(0) = 15° от вертикали; ω1(0) = ω2(0) = 0. Гравитация g = 9.81 м/с².
- Метод и параметры: системы динамики решается численно с помощью метода Рунге–Кутты 4-го порядка (RK4) с фиксированным шагом dt = 1e-3 s на интервале T = 20 s (около N ≈ 20000 шагов). Выводятся траектории θ1(t), θ2(t), а также ω1(t), ω2(t); по желанию — Cartesian координаты грузов x1, y1, x2, y2.
- Выход: временные траектории углов, скоростей и (при необходимости) координаты грузов.

2) Объяснение уравнений движения (PDE/ODE explanation)
- Суть уравнений: задача приводится к системе двух уравнений движения, сформированной через линейную систему M * [θ1¨, θ2¨]^T = b, где:
  - Δ = θ1 − θ2 — относительный угол между звеньями.
  - Матрица инерции M = [ [ (m1+m2) l1, m2 l2 cos Δ ],
                          [ m2 l1 cos Δ, m2 l2 ] ].
  - Правая часть b = [ b1, b2 ]^T, где
    - b1 = − m2 l2 ω2² sin Δ − (m1+m2) g sin θ1
    - b2 =  m2 l1 ω1² sin Δ − m2 g sin θ2
- Физический смысл:
  - M отражает распределение инерции системы и связь между ускорениями θ1¨ и θ2¨ из-за геометрии звеньев.
  - b содержит вклад гравитации (потенциальная энергия и её градиент), а также не-линейные эффекты, связанные с угловыми скоростями (Coriolis/centrifugal-подобные члены, через sin Δ и ω²).
- Непрерывность: задача описывает механическую систему без демпинга, т. е. энергия системы в номинальной идеальной постановке изменяется только за счёт гравитации и геометрии, а не за счёт искусственных источников сил.

3) Анализ кода (block-level)
- Импорты и подготовка:
  - Импортируются numpy, math и matplotlib.pyplot для численного вычисления и визуализации.
- Функция derivatives(state, l1, l2, m1, m2, g):
  - state = [θ1, θ2, ω1, ω2].
  - Вычисляется Δ, строится матрица M и правая часть b.
  - Решается линейная система M * acc = b для ускорений acc = [θ1¨, θ2¨].
  - Возвращается вектор производной состояния: [dθ1/dt, dθ2/dt, dω1/dt, dω2/dt] = [ω1, ω2, θ1¨, θ2¨].
- Функция rk4_step(state, dt, ...):
  - Реализация шага RK4: вычисления k1..k4 и обновление состояния.
- Функция simulate(dt, T):
  - Задаются параметры задачи: l1=5, l2=1, m1=1, m2=3, g=9.81.
  - Начальные условия: θ1_0 = 10° (рад), θ2_0 = 15° (рад), w1_0 = w2_0 = 0.
  - Инициализация массивов времени, состояний и координат грузов (x1,y1,x2,y2).
  - По времени выполняется цикл интегрирования с RK4, заносится состояние и координаты грузов на каждом шаге.
  - Есть опция verbose для вывода финальных значений после симуляции.
  - Возвращает times, states, x1, y1, x2, y2.
- Функция main():
  - Запуск simulate и построение графиков:
    - θ1(t) и θ2(t)
    - ω1(t) и ω2(t)
    - Cartesian-позиции грузов (m1 и m2) в декартовой системе, если включено визуализировать.
- Важное замечание: углы отсчитываются от вертикали; координаты масс в декартовой системе вычисляются через x1 = l1 sin θ1, y1 = l1 cos θ1 и далее x2 = x1 + l2 sin θ2, y2 = y1 + l2 cos θ2.

4) Критические факторы и чувствительность (Critical Factors)
- Временной шаг dt:
  - dt = 0.001 с обеспечивает высокую временную точность для заданного диапазона T = 20 с. Но для более длинных интеграций или при стремительных режимах dt может понадобиться меньший шаг или использование более устойчивого интегратора.
- Начальные углы и массы:
  - m2 и l2 влияют на силу связи между звеньями; значительная разница масс может усилить нелинейность и привести к более чувствительной к начальному состоянию динамике (возможна хаотичность в определённых режимах).
- Углы Δ и синусы:
  - При Δ близком к 0 или π, матрица M может быть близка к вырожденной по числу; в данной постановке 2x2 решается напрямую, риск численной нестабильности минимален, но аккуратность вычислений важна.
- Энергия и устойчивость:
  - В идеальной несомкнутой системе без демпинга численное интегрирование может приводить к постепенному дрейфу энергии из-за аппроксимации; RK4 обычно обеспечивает хорошую точность, но для долговременной эволюции полезно мониторить энергию и рассмотреть симплицитный интегратор.
- Вывод результатов:
  - Траектории θ1(t), θ2(t) могут выглядеть синфазно или нелинейно, сильно зависят от начальных условий; вывод Cartesian координат полезен для визуализации траекторий грузов и проверки геометрии звеньев.

5) Численные и оптимизационные аспекты (Numerical and Performance Considerations)
- Использование RK4:
  - Хороший компромисс между точностью и вычислительной затратой для не-стихой, не-жёсткой динамики двойного маятника.
  - Нет явной необходимости в сложной адаптивной схеме, но возможно применение симплкитических интеграторов (например, Verlet/Stormer) для лучшего сохранения энергии в бездемпинговой системе.
- Производительность:
  - Решение 2x2 линейной системы на каждом шаге (очень быстро) делает код эффективным для заданных параметров.
  - Векторизация и нюансы памяти не критичны здесь, но можно рассмотреть NumPy-векторизацию или Numba для ускорения при более длительных экспериментальных сериях.
- Валидация и проверки:
  - Полезно сравнивать RK4-результаты с другими методами интегрирования (например, Verlet или булевыми методами) на коротком отрезке времени, чтобы проверить корректность реализации.
  - Мониторинг энергии E = KE + PE может помочь обнаружить численное поведение, если энергия непреднамеренно «растёт» или «убывает».
